## 🎯 Padrão Adotado
Os registros seguem o padrão canônico **MADR / Nygard**, garantindo rastreabilidade estruturada:
- **Contexto**: A motivação, o problema técnico e o estado prévio.
- **Decisão**: A solução técnica acordada e adotada.
- **Consequências**: Os benefícios obtidos e eventuais trade-offs assumidos.
